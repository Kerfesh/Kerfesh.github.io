## Файл TikTok
В TikTok сначала укажите НОВЫЙ префикс https://kerfesh.github.io/.
Скачайте файл, который TikTok выдаст именно для этой проверки, и загрузите его в корень репозитория с точным именем (без (1)). Не меняйте содержимое.
Старый файл был выдан для Notion-префикса, поэтому не включён в этот архив.
Дождитесь развёртывания. Проверьте прямой HTTPS-адрес файла без перенаправления. Затем нажмите Verify в TikTok.

Этот сайт не является работающей веб-панелью TikTok. Проверка URL не отменяет правила TikTok, включая ограничения личных/внутренних приложений. Одобрение API не гарантируется.
Никаких токенов, секретов, исходников бота или базы данных здесь нет.

Документы — статические копии согласованных текстов. Изменения в Notion НЕ обновляют сайт автоматически. При изменении правил обновляйте оба места.
Техническая строка проверки удалена только из HTML-копии условий; Notion-оригинал не изменялся.
